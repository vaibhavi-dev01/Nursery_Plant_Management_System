# 🌱 Nursery Plant Management System

A web-based **Nursery Plant Management System** developed during my internship at **Passion Software Solutions, Jalgaon**. The project was developed using Python and Django to manage nursery plants and provide users with an easy-to-use platform for accessing plant-related information.

## 📌 Project Overview

The Nursery Plant Management System is designed to digitally manage nursery plant information and make plant management easier through a web-based application.

The project helped me gain practical experience in **Python, Django, HTML, CSS, JavaScript, and SQLite3**, along with understanding how a web application is structured and developed.

## 🎯 Objectives

* To develop a web-based nursery plant management system.
* To organize and manage plant information digitally.
* To provide an easy-to-use interface for users.
* To understand backend development using Django.
* To gain practical experience in database integration and web application development.

## ✨ Features

* 🌱 Plant information management
* 🔍 Plant search and browsing
* 📋 Plant details and information
* 👤 User-friendly web interface
* 🔐 Django-based backend
* 🗄️ Database integration using SQLite3
* 📱 Responsive web interface
